# Roadmap — candidate next features (v3)

**Not commitments.** Ideas for the work queue after [stories/index.md](stories/index.md) milestones. Slice and prioritize in planning sessions.

## Assist and sensing

- Export or save **draft** location picture as a file (alongside copy semantics in [US-5-1](stories/US-5-1-draft-location-diagram-reviewable.md)).
- **Replay-linked** revision of a draft map when the user jumps backward in a recorded session (requires replay story later).
- Richer session signals (for example inventory-like hints) with the same **honest** and **bounded** rules as [US-4-1](stories/US-4-1-session-signals-visible.md).

## Trust and operations

- CI gates that run **smoke** tests for ancillary panels when present (without slowing the core CRT wire tests).
- Operator-facing clarity for oracle modes (see backlog in [deferred.md](deferred.md): health fields, teardown of persistent Fortran children).

## Integration

- Optional **client-direct** model calls for map draft only, with posture-gated confirmation ([design-agentic-mvp.md](design-agentic-mvp.md))—only if in-product policy allows.
