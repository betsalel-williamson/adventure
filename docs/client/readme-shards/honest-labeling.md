# Honest labeling

- **Draft assistance** — exploration maps and assist hints infer structure from the **visible transcript**; Fortran remains truth.
- **Heuristic adapter** — deterministic merge and compass policy; **not** an SLM or multi-agent LLM run.
- **SLM / LLM** — when `OLLAMA_URL`, MLX, Gemini, or HTTP providers are configured, label research notes with the actual backend.

When assist or autoplay is off or unreachable, UI copy should still describe draft/inferred surfaces honestly.
