# Play prerequisites

- **Node.js 24+** — use repo [`.nvmrc`](../../.nvmrc) (`nvm use` / `fnm use`)
- **npm** — install dependencies in the package directory before `npm start`
- **GNU Fortran** (`gfortran`) — optional; for real cave text run `make adventure` at repo root

```bash
node --version   # expect v24.x
```
