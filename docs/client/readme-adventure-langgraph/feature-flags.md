# Feature flags

Defaults favor **game-first** play: exploration map and location agent on; legacy Assist panels off.

| Flag | Default |
| --- | --- |
| `explorationMap` | on |
| `locationAgent` | on |
| `assistPanels` | off |
| `mapProbe` | off |
| `mapInspectors` | off |

Product behavior: [`docs/features/crt-shell.md`](../docs/features/crt-shell.md). Env overrides and `sessionStorage` keys: [`docs/developer/langgraph-feature-flags.md`](../docs/developer/langgraph-feature-flags.md).
